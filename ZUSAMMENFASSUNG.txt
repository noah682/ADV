UML to Java Converter – Projektzusammenfassung
================================================
Stand: 2026-06-29

WAS GEMACHT WURDE
-----------------

Block 1 – UTF-8 Fix (Umlaute)
  UMLReader.java:     XML via InputStream gelesen, XML-Deklaration (encoding="UTF-8") wird korrekt ausgewertet.
  ClassGenerator.java: Files.writeString(..., StandardCharsets.UTF_8) – alle .java-Dateien UTF-8-kodiert.
  Ergebnis: TestCase7 (Zerstörbar, Gerät, zerstöre()) läuft komplett durch.

Block 2 – Interface-Generierung
  - <<interface>> / «interface» erzeugt jetzt: public interface X { ... }
  - Methoden nur als Signaturen mit Semikolon, ohne Rumpf, ohne Sichtbarkeits-Modifier.
  - Keine Felder, kein Konstruktor, keine Getter/Setter für Interfaces.
  Ergebnis: Controllable.java, Fortbildung.java (Interface-Variante) kompilieren.

Block 3 – Gültige Java-Bezeichner
  UMLParser.sanitizeIdentifier(): entfernt alle ungültigen Zeichen (z.B. "-").
  - Online-Fortbildung  →  OnlineFortbildung
  - /Gerät/             →  Gerät (abstract), Schrägstriche gestripped
  - /berechnet          →  berechnet (führendes / entfernt)
  Ergebnis: Alle TestCases erzeugen nur gültige Java-Bezeichner.

Block 4 – Umlet-Styling-Zeilen ignorieren
  isUmletProperty(): Zeilen mit Muster "key=..." (lt=<<-, bg=yellow, m1=, m2= usw.) werden
  vollständig ignoriert – weder als Klassenname noch als Member.
  Ergebnis: Keine Junk-Klassen mit "=" im Namen mehr.

Block 5 – Enum-Feinschliff
  - Guillemets «enum», «enumeration», «enumerations» werden erkannt (zusätzlich zu <<...>>).
  - Enum-Konstruktoren werden als private ausgegeben.
  - Konstanten mit führendem Sichtbarkeitszeichen (- LIGHT) werden korrekt erkannt.
  - Enum-Konstanten erhalten automatisch Default-Konstruktorargumente wenn nötig (MONTAG(null)).
  Ergebnis: TestCase4/5 erzeugen kompilierende Enums; DeviceType enthält LIGHT, HEATER, CAMERA.

Block 6 – Vererbung aus Relationen
  NICHT implementiert (zu aufwändig/unsicher ohne koordinatenbasierte Zuordnung).
  Dokumentiert als bekannte Grenze in der README.

Block 7 – JavaDoc

    UMLReader.java, UMLParser.java, DataSave.java, ClassGenerator.java,
    Main.java, UmlLauncherApp.java

Block 8 – README
